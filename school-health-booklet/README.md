## ساخت دوباره

```bash
cd src
./build.sh
```

- `src/topics.js` — متن همهٔ موضوع‌ها (برای ویرایش متن فقط همین فایل را تغییر دهید)
- `src/booklet.html` — قالب صفحه‌ها؛ اندازهٔ محتوای هر صفحه خودکار تنظیم می‌شود تا صفحه پر شود و چیزی بیرون نزند
- `src/characters.js`، `src/scenes.js` — شخصیت‌ها و تصویرهای برداری
- `src/render.js` — ساخت PDF و بررسی سرریز متن و فاصله از لبهٔ صفحه
- آیکون‌های کوچک از فونت Noto Color Emoji (مجوز OFL) هستند؛ همهٔ متن‌ها با فونت B Titr نوشته شده‌اند.
