# پوستر آموزشی «مراقبت‌های آنفولانزا» — ویژهٔ دانش‌آموزان دبستان

پوستری یکپارچه به اندازهٔ **۴۲ × ۵۹٫۴ سانتی‌متر** که از **چهار برگهٔ A4 عمودی** (چیدمان ۲ × ۲) ساخته می‌شود.
همهٔ متن‌ها با فونت «تیتر» (B Titr)، راست‌چین و بر اساس محتوای خواسته‌شده نوشته شده‌اند.

![پیش‌نمایش پوستر](output/preview.jpg)

## فایل‌های خروجی (`output/`)

| فایل | کاربرد |
|---|---|
| `influenza-poster-full-300dpi.png` | تصویر یکپارچهٔ پوستر، ۴۹۶۰ × ۷۰۱۶ پیکسل، ۳۰۰ dpi |
| `influenza-poster-A2-full.pdf` | همان پوستر به صورت PDF برداری، یک صفحهٔ دقیقاً ۴۲۰ × ۵۹۴ میلی‌متر (برای چاپخانه) |
| `influenza-poster-4xA4-sheets.pdf` | چهار صفحهٔ A4 دقیق (۲۱۰ × ۲۹۷ میلی‌متر) برای چاپ با چاپگر معمولی |
| `sheets-A4-png/sheet-1-top-right.png` … `sheet-4-bottom-left.png` | چهار برگهٔ جداگانه به صورت تصویر، هر کدام ۲۴۸۰ × ۳۵۰۸ پیکسل (A4 در ۳۰۰ dpi) |
| `assembly-guide.png` | راهنمای ترتیب برگه‌ها و چسباندن |
| `preview.jpg` | پیش‌نمایش کم‌حجم |

ترتیب برگه‌ها (مطابق جهت خواندن فارسی): **۱** بالا راست، **۲** بالا چپ، **۳** پایین راست، **۴** پایین چپ.

## راهنمای چاپ

1. در تنظیمات چاپ، اندازه را روی «اندازهٔ واقعی / Actual size / ۱۰۰٪» بگذارید (نه Fit to page).
2. اگر چاپگر حاشیهٔ سفید گذاشت، حاشیه‌ها را ببرید و برگه‌ها را مطابق `assembly-guide.png` کنار هم بچسبانید.
3. دور هر برگه ۱۲ میلی‌متر فقط پس‌زمینه است؛ هیچ متن، کادر یا چهره‌ای روی خط اتصال یا لبهٔ برگه‌ها نیست.
   این موضوع هنگام ساخت به‌صورت خودکار بررسی می‌شود (`render.js`).

## ساخت دوباره

```bash
cd src
./build.sh        # فونت را (در صورت نبود) دریافت می‌کند، سپس همهٔ خروجی‌ها را می‌سازد
```

پیش‌نیازها: Node.js با Playwright/Chromium، و Python 3 با `Pillow` و `pypdf`.

- `src/poster.html` — چیدمان، متن‌ها و رنگ‌ها (واحدها بر حسب میلی‌متر)
- `src/illustrations.js` — شخصیت‌ها و آیکون‌های برداری (SVG)
- `src/render.js` — خروجی PNG و PDF و بررسی حاشیهٔ امن و سرریز متن
- `src/split.py` — برش به چهار برگهٔ A4 (PNG و PDF)
- `src/guide.js` — ساخت راهنمای چسباندن

فایل فونت B Titr در مخزن قرار نگرفته است؛ `src/fetch-font.sh` آن را از بستهٔ npm
`@raha.group/persian-fonts` دریافت می‌کند.
