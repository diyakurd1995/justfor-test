ساختار هر کتابچه: جلد ← فهرست، هدف‌های یادگیری و پیام برای اولیا و مربیان ← بخش‌های آموزشی (هر زیرسرفصل یک بخش) ← بازی و تمرین «درست یا نادرست؟» و جدول عادت‌ها ← پیمان من و پاسخ تمرین‌ها.
نام گردآورنده روی جلد و در پانویس همه صفحه‌ها آمده است. پیش‌نمایش همه صفحه‌ها در `output/preview/` است.

## ساخت دوباره

```bash
cd src
./build.sh          # همه سرفصل‌ها
./build.sh 04       # فقط یک سرفصل
```

- `src/units/u01.js` … `u09.js` — متن هر سرفصل (برای ویرایش متن فقط همین فایل‌ها را تغییر دهید)
- `src/unit.html` — قالب صفحه‌ها؛ اندازه محتوای هر صفحه خودکار تنظیم می‌شود
- `src/characters.js`، `src/scenes.js`، `src/scenes2.js` — شخصیت‌ها، صحنه‌ها و تصویرهای آموزشی برداری
- `src/render.js` — ساخت PDF و بررسی سرریز متن و فاصله از لبه صفحه
- آیکون‌های کوچک از فونت Noto Color Emoji (مجوز OFL) هستند و همه متن‌ها با فونت B Titr نوشته شده‌اند.
